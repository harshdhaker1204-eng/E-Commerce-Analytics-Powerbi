# E-Commerce Analytics Dashboard

## 📊 Project Overview

An end-to-end E-Commerce Analytics project using Python, SQL, and Power BI to analyze sales, customer behavior, products, payments, and business performance.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- MySQL
- Power BI
- Jupyter Notebook

## 📂 Dataset

The dataset used in this project was downloaded from Kaggle.

**Dataset:** Retail Store Sales  
**File:** `retail_store_sales.csv`  
**Source:** Kaggle

The dataset contains transaction-level information such as:

- Transaction ID
- Customer ID
- Category
- Item
- Price Per Unit
- Quantity
- Total Spent
- Payment Method
- Location
- Transaction Date
- Discount Applied

## 📈 Dashboard

The Power BI dashboard provides insights into:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Sales by Category
- Sales by Location
- Sales by Payment Method
- Sales Trend over Time
- Sales by Discount
- Sales by Item

## 🔍 Analysis

### Python
Performed data cleaning and exploratory data analysis using Pandas, NumPy and Matplotlib.

### SQL
Performed business analysis using SQL queries including:

- Total Revenue
- Average Order Value
- Total Orders
- Highest and Lowest Orders
- Category Analysis
- Customer Analysis

### Power BI
Created an interactive dashboard to visualize key business KPIs and sales trends.
